# MANUAL BILLING CAPTURE CHECKLIST — ACTUAL ACCRUED COST

Purpose: record ACTUAL Railway dollars separately from engineering projections.

When user is home:
1. Open Railway workspace/project billing or usage page.
2. Capture current billing period start/end.
3. Capture current accrued usage total in dollars.
4. Capture included plan credit/subscription amount separately.
5. If Railway provides resource breakdown, capture:
   - CPU
   - Memory
   - Network egress
   - Storage/volume
   - any build/other usage
6. Capture forecast/estimated invoice separately if shown.
7. Do not treat forecast as already owed.
8. Record screenshot/time because usage can continue changing.

Report format:
- Already accrued usage: $X as of timestamp.
- Plan/subscription: $Y.
- Credits/included usage: $Z.
- Net current amount if Railway displays it: $N.
- Forecast: $F (forecast only).
- Pre-fix vs post-fix usage interpretation with dates.

No attempt should be made to derive 'actual spent' solely from service metrics when Railway billing UI is authoritative.
